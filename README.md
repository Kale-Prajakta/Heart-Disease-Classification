# 💓 Heart Disease Classification

---

## 🔍 Objective

- Perform classification using **Logistic Regression**.
- Understand model performance using **Accuracy**, **Precision**, **Recall**, and **F1-score**.
- Evaluate model behavior for **overfitting** and **underfitting**.

---

## 📂 Dataset Overview

- **Source**: Kaggle  
- **Link**: [Heart Disease Dataset - Kaggle](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset)  
- The dataset contains 14 columns including features like age, sex, chest pain type, cholesterol, max heart rate, etc., and a binary target variable indicating heart disease presence.


---

## 🛠️ Tools Used

- Python (Jupyter Notebook)
- Pandas, NumPy
- Matplotlib, Seaborn
- scikit-learn

---

## 📈 Models & Evaluation

- **Logistic Regression** (main classifier)
- **Linear Regression** (for comparison)
- Evaluation metrics:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - Confusion Matrix

---

## 📊 Highlights

- Exploratory Data Analysis (EDA): Distributions, correlations, and boxplots.
- Model trained using `train_test_split`.
- Balanced and interpretable performance metrics.
